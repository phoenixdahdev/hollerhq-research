# Ecosystem Research — Overview

ecosystem that warrant analysis beyond the market-level view in
`../08-competitive-landscape.md`.

Each file in this folder:

- Documents one external project / company
- Assesses what we can adopt, study, or avoid
- Notes competitive positioning if relevant
- Recommends concrete actions

## Process

When evaluating a new ecosystem project, the deep dive should answer:

1. What is it? (one paragraph)
2. What does it ship? (OSS repos, licenses, hosted services)
3. What can we adopt directly?
4. What can we study but not adopt?
5. What should we avoid (license issues, coupling)?
6. Competitive implications (if any)
7. Recommended action plan
8. How to peek hands-on (short validation spike)

Use `01-kapso.md` as the template.
